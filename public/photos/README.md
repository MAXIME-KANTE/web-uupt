# Dossier `photos/` — Images d'illustration du site UUPT

Deposez ici les futures photos officielles de l'Union.
Tant qu'un fichier est absent, le site affiche automatiquement
l'image de secours (Unsplash) definie dans `src/data/uuptData.ts`.

Fichiers attendus (noms exacts) :
- `hero-bg.jpg`      (1920 px de large — photo grand angle, hero de l'accueil)
- `campus-thies.jpg` (1200 px — vie etudiante a Thies, page A propos)
- `axe-academique.jpg` (900 px — bibliotheque / panel / plaidoirie)
- `axe-innovation.jpg` (900 px — prototypes et projets techniques)
- `axe-sport.jpg`      (900 px — tournois inter-etablissements)

Formats acceptes : `.jpg`, `.png`, `.webp`.
Le logo du site reste a la racine : `public/dame.png`.
